# Diététiciens libéraux de La Réunion

Annuaire des diététiciens libéraux adhérents : carte des communes, liste par commune, trombinoscope et fiches détaillées.

Site : https://tic974.github.io/annuaire-dieteticiens/

## Mettre à jour l'annuaire

La mise à jour se fait avec un agent IA (Claude, ChatGPT/Codex, Copilot…) ouvert dans ce dépôt. Les consignes détaillées pour l'agent sont dans [AGENTS.md](AGENTS.md).
